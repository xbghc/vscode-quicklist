# Changelog

## 0.3.1 - 2026-10-23

- Keep an empty Quicklist blank by removing welcome instructions and the empty-state folder link.
- Show the Explorer drag hint only when Quicklist contains items.

## 0.3.0 - 2026-10-22

- Create and rename grouping folders directly in the sidebar, with Enter/Escape and inline validation.
- Drag Quicklist items to reorder them, move between folders, or return to the root.
- Import Explorer files and folders by holding Shift while dragging into the sidebar.
- Preserve shortcut storage, nested contents, workspace checks, and persisted ordering.

## 0.2.0 - 2026-10-22

- Create and rename grouping folders, including nested subfolders.
- Move shortcuts or whole groups to another folder or back to the Quicklist root.
- Add the active file directly to a group from its context menu.
- Remove grouping folders while keeping their contents one level up.
- Preserve existing flat lists and persist folder organization per workspace.

## 0.1.0

- Add a flat Quicklist view to Explorer.
- Add the active file with one click, or add files and folders from Explorer.
- Open file shortcuts and reveal folder shortcuts in the native Explorer.
- Remove shortcuts without changing the file system.
- Preserve insertion order and store each workspace's list independently.
- Preserve resource URIs and keep missing entries visible and removable.
